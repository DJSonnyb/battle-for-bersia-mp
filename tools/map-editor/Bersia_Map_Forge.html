Waves - quick guide

The map tools are hidden while you edit waves. Press Back to the map to use them again.

  1. Each group is a row: its troops attack in every wave from its first to its last.
  2. Add troops with + troop. Click a troop to find it in Wave troops, where you can change what it is.
  3. Each wave picks one of the spawn areas at random. Drag the blue boxes on the map to move them.
  4. Fix anything in the orange Check these box before you export.

How to make a map

  1. Open a map to start from. Press Open map files… and pick all three files of one map from your game folder, Data\Mission\Live: the .map (the ground), the .stg (troops, starts, spawn areas and waves) and the .dds (the minimap). Start from a map of the mode you want: the 4_ and 6_ maps are Versus, 8_Ruin and 9_IceStorm are Invasion. The map shown before you open anything is a made-up example for trying the tools.
  2. Change it with the tools on the left. Click a tool, and the panel on the right says what it does and shows its settings. Mouse wheel zooms; drag with the right mouse button to move the view. Ctrl+Z undoes, Ctrl+Y redoes.
  3. Place the troops. With Select (the top tool), drag a player's troops or a blue spawn area. Q and E turn the selected troop. Versus maps: choose the number of players under Sides and spawn areas.
  4. Invasion maps: set the waves. Press Waves to choose which enemy troops come in each wave. The waves page has its own guide.
  5. Save project keeps your work so you can carry on another day. It only holds your changes, so to reopen it, open the same three original map files and the project file together.
  6. Export for the game makes the playable map, a .zip. Unzip its Data folder into your Kingdom Under Fire: Heroes folder (next to Heroes.exe). It shows in the lobby as Custom: name. Players who join without it get it from the host automatically.

Good to know

  • Map name: up to 27 letters, numbers, - or _. It can't be the name of one of the game's own maps (such as 9_IceStorm), and the lobby shows up to 8 custom maps.
  • Always export with the .stg open, or the map has no troops and won't show in the lobby.
  • Block paints red marks, but troops can still walk through them for now: the game needs a navigation (.nav) file for that, which the editor can't make yet.
  • Layers (right panel) only change what you see in the editor, never the map.
  • A cell is 1.25 m. Heights are in centimetres.
