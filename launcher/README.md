# Battle for Bersia MP - Launcher

A small Windows launcher (one .exe, no install) that replaces downloading a new installer .bat for every update.

- Put `BattleForBersiaLauncher-X.Y.Z.exe` in the KUF Heroes folder (next to Heroes.exe), or pick the folder from the launcher.
- On start it reads the GitHub Releases of this repository and offers INSTALL / UPDATE when a newer release has a `*_Install.bat` asset.
  The installer is downloaded into the game folder and run as before - it patches the player's own Steam files; nothing from the game is shipped.
- Settings: "Receive test builds" also takes pre-releases (for testers); "Encablossa edition" takes the `*E_Install.bat` asset.
- LAUNCH GAME starts the game through Steam (app id read from the Steam library's appmanifest).
- Graphics options are written to `Documents\KUF2 Heroes\KUFH.ini` (same keys as the in-game Graphics page).
- The launcher updates itself when a release has an asset named `BattleForBersiaLauncher-X.Y.Z.exe` with a higher version.

## Publishing a release the launcher picks up
- Tag e.g. `v1.5` (stable) or `v1.5-test19` (mark as **pre-release**).
- Assets: `BattleForBersiaMP_v1.5_Install.bat`, optionally `BattleForBersiaMP_v1.5E_Install.bat`, optionally `BattleForBersiaLauncher-1.0.1.exe`.
- The release text is shown in the launcher's news panel (simple Markdown: headings, `-` lists).

## Building
`launcher/build_launcher.sh` (clang, lld-link, llvm-dlltool, llvm-rc, Python 3 + Pillow). Output: `launcher/out/BattleForBersiaLauncher.exe`.
Artwork is generated by `make_art.py` (no game files).
